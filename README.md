I build software where people and AI agents share a source of truth, and the record of who said what stays intact. Before that, I spent a PhD at UCL turning terrestrial LiDAR point clouds into 3D models of tree structure.

## Now

**[Ontolith](https://github.com/ontolith/ontolith)** is an open-source Python library (Apache-2.0) for shared, governed knowledge bases. Facts are append-only and bitemporal, agents propose instead of writing, and disagreements go to a human reviewer instead of being overwritten.

```bash
pip install ontolith
```

[Documentation](https://ontolith.github.io/ontolith/) · [Specification](https://github.com/ontolith/ontolith/blob/main/docs/Ontolith_SPEC.md) · [Design decisions](https://github.com/ontolith/ontolith/tree/main/docs/adr)
